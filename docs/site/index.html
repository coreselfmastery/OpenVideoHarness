01Get started快速开始

One line to install. One sentence to ask.一行命令安装，一句话提需求。

  1. Install (macOS or Linux)安装（macOS 或 Linux）

    $ curl -fsSL https://raw.githubusercontent.com/ZLHad/OpenVideoHarness/main/install.sh | bash

  2. Open Claude Code in it进入目录，打开 Claude Code

    $ cd ~/OpenVideoHarness && claude

  3. Ask for a film一句话提需求

    “Make a 30-second vertical science short: why does a low-orbit satellite's signal change pitch? English voiceover, English and Chinese subtitles.”
    “做一个 30 秒的竖屏科普：为什么低轨卫星的信号会‘变调’。中文配音，中英双语字幕。”

Needs macOS or Linux, Node.js 22+, Chrome, FFmpeg, Python 3 with uv, and Claude Code or Codex. About 590 MB on disk, with 30 read-only reference repos.需要 macOS 或 Linux、Node.js ≥ 22、Chrome、FFmpeg、Python 3 和 uv，以及 Claude Code 或 Codex。连同 30 个只读的参考仓库，约占 590 MB。

What happens next接下来

  1. ① Directions and outline① 创意方向和大纲Two or three ideas, each with one frame. You pick one.两三个创意方向，各配一帧画面，你选一个。
  2. ② Storyboard② 分镜A keyframe for every shot.每个镜头一张关键帧。
  3. ③ First draft③ 初版With the two or three things it likes least about it.附上它自己最不满意的两三处。
  4. Final render出成片Only after you say yes.你点了头才出。
quickno stops · 10–30 min不停 · 10–30 分钟
standardthree stops · 1–2 h停三次 · 1–2 小时
studiopolished over rounds · 3 h+多轮打磨 · 3 小时以上

Times are for a 30-second film. Say "quick" and it runs straight through.时间按 30 秒的片子算。说"快速出一版"，它就一口气做完。

02Why it exists为什么做它

One great film is easy. Every time is hard.做出一支好片不难，每次都好才难。

Claude Opus 5.5 writes video as code, and it has taste: in motion, in type, in pacing. The community has shared hundreds of these films; one collection alone holds 389, with their prompts.Claude Opus 5.5 能用代码写视频，而且有审美：运动、字体、节奏都在线。社区里已经有几百支这样的片子，光一个合集就收了 389 支，连同提示词。

But the same model can be brilliant once, then lose the pacing, glow everything and invent numbers the next time. Engines like HyperFrames and Remotion turn code into frames. They don't choose the idea, the storyboard, the script or the style, and can't tell whether the film is any good.可同一个模型，这次惊艳，下次就节奏乱、满屏发光、数字乱编。HyperFrames、Remotion 这些引擎负责把代码变成画面；立意、分镜、脚本、风格它们不管，片子好不好也判断不了。

OpenVideoHarness is the missing layer: the process and the checks, from idea to final cut, written as docs an agent follows. It stays light on purpose: a few hard floors, and defaults that a good idea can overrule.OpenVideoHarness 补的就是这一层：从立意到成片的流程和检查，写成 agent 能照着做的文档。它故意写得很轻：几条底线不让步，其余都是默认，好点子可以反着来。

You decide, three times三次由你拍板

04

It checks its own work自己检查自己

Claude can't watch video. So it reads contact sheets against a 20-point checklist, measures the audio, and a second Claude with a fresh context scores the draft on 8 points.Claude 看不了视频，所以它看联系表、对照 20 条清单改，用数据查声音；再由一个全新上下文的 Claude 按 8 项给初版打分。

templates/TASTE_CHECKLIST.md
05

Sound, as code声音也是代码

Chinese and English voiceover, two-language subtitles, a score and 21 sound effects written as code, every cue on its frame, mixed to −14 LUFS.中英配音、双语字幕，配乐和 21 个音效都用代码写，每个卡点落在它那一帧，混音到 −14 LUFS。

bin/vh tts · music · sfx · mix · qa
06

Every frame is f(t)每一帧都是 f(t)

No randomness, no clock, no state carried between frames. Same t, same pixels, so any frame renders alone, in parallel, in any order, and can be checked. Drag the slider, then render the frame again.不用随机数、不读时钟、帧与帧之间不留状态。同一个 t 永远是同一帧，所以任何一帧都能单独渲染、并行渲染、乱序渲染，也能抽查。拖动滑块，再把这一帧重渲一遍试试。

CLAUDE.md · hard rule 1
t = 0.00 s · frame 01 sine wave
07

31 styles, and Blender31 种风格，外加 Blender

A style library to borrow from, each with a rendered sample. And when a shot needs real glass or a million stars, Claude drives Blender from Python.风格库可以借来用，每种都带实际渲染的样片。要真玻璃、上百万颗星时，Claude 写 Python 驱动 Blender。

09FAQ常见问题

Good questions, straight answers.常见问题，一次说清。

More in the wiki更多见 Wiki ↗
How is this different from just asking an agent?和直接让 AI 做有什么不同？
An agent alone has taste but no process: nothing tells it to settle the idea before code, to check its frames, or to stop for you. We ran one small blind comparison: the workflow's films had the fresher ideas, while the floors-only films were judged better made, and what the reviewer flagged went into the checks. The process aims to save rework; that saving hasn't been measured yet. The comparison ↗单靠 agent，有审美，但没有流程：没人让它先定立意再写代码、检查自己的帧、停下来等你。我们做过一次小的盲评：按流程做的点子更新，只守底线做的被评为做工更好；评审指出的问题后来都补进了检查。流程想省的是返工，这一点还没有量过。实验记录 ↗
What does it cost?要花多少钱？
Rendering, music and sound effects run locally and cost nothing. What costs money is the agent itself (a Claude Code or Codex subscription, or API usage), plus any cloud voice or generated video you choose, billed by that provider. Keys are always read from environment variables.渲染、配乐、音效都在本地跑，不花钱。要花的是 agent 本身（Claude Code 或 Codex 的订阅或 API 用量）；接云端配音或生成式视频时，按各家收费。key 一律从环境变量读。
How long does a film take?做一支要多久？
For a 30-second film: about 10–30 minutes at quick, 1–2 hours at standard, 3 hours or more at studio. Most of the time goes into checking and fixing. All three levels deliver a full-quality film; the level sets how often it stops and how many review rounds it runs.30 秒的片子：快出档 10–30 分钟，标准档 1–2 小时，精品档 3 小时以上，大部分时间花在自查和返工上。三档出的都是正式画质的成片，档位管的是中途停几次、审几轮。
What do I need?需要什么环境？
macOS or Linux, Node.js 22+, Google Chrome, FFmpeg, Python 3 with uv, and Claude Code or Codex. The local voice needs Apple Silicon (a cloud voice doesn't), formulas need LaTeX, and only 3D shots need Blender 5.2. Windows is untested.macOS 或 Linux、Node.js ≥ 22、Google Chrome、FFmpeg、Python 3 和 uv，以及 Claude Code 或 Codex。本地配音要 Apple Silicon（换云端配音就不用），公式要 LaTeX，只有 3D 镜头才要 Blender 5.2。Windows 没有测过。
Does it work with Codex?能用 Codex 吗？
Yes. AGENTS.md carries the same instructions as CLAUDE.md, and the installer registers the open-video-harness skill for both Claude Code and Codex, so asking for a video from any folder finds the workbench.能。AGENTS.md 和 CLAUDE.md 内容相同；安装时 open-video-harness skill 会同时注册给 Claude Code 和 Codex，之后在任何目录说"做个视频"，都能找到这里。
Which languages does it speak?支持哪些语言？
Chinese and English. Voiceover runs on the local, open-source Qwen3-TTS by default, with cloud voices as options, and subtitles come in either language or both. Ask in either language; the review pages follow yours.中文和英文。配音默认用本地开源的 Qwen3-TTS，也能接云端配音；字幕可以出中文、英文或双语。需求用哪种语言都行，审阅页跟着你的语言走。
Can it make films with real people?能做真人、实拍感的片子吗？
Realistic people and a live-action look need generated video; the playbook shows how to combine generated clips with code-drawn overlays. Editing footage you shot yourself (talking heads, interviews, vlogs) is type 09, still experimental.写实人物、实拍感要靠生成式视频，playbook 里有一套"生成式视频 + 代码叠加"的做法。剪你自己录的素材（口播、访谈、Vlog）是第 09 类，还在试验。
What can't it do yet?现在还做不到什么？
The agent can't watch or listen. It reads rendered frames and audio measurements, so the last look and listen are yours. The full workflow has only been run on macOS (Apple Silicon), and type 09 hasn't been tried on real footage yet.agent 看不了视频、听不了声音，只能看渲染出的帧、读声音的数据，所以最后一关还是要你看、你听。目前只在 macOS（Apple Silicon）上完整跑过，第 09 类剪辑还没用真实素材试过。
Is it an Anthropic project?是 Anthropic 官方项目吗？
No. It's an independent open-source project under the MIT license, not affiliated with Anthropic, HeyGen or Remotion.不是。这是独立的开源项目，MIT 许可，和 Anthropic、HeyGen、Remotion 都没有隶属关系。
How can I contribute?怎么参与？
Pull requests are welcome: new video types, styles with their samples, case studies, lessons from your projects, and films you made with it, with everything that went into them. CONTRIBUTING.md ↗欢迎提 PR：新的视频类型、带样片的风格、案例拆解、项目里踩过的坑，以及你用它做的片子和全部制作过程。CONTRIBUTING.md ↗
